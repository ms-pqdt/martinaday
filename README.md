# Martina está a caminho! 🐶✈️

Contagem regressiva em pixel art para a chegada da Martina (Colômbia → Rio de Janeiro) em 15/12/2026.

Site estático em um único arquivo (`index.html`). Para publicar no GitHub Pages:
Settings → Pages → Deploy from a branch → `main` / `(root)`.

Para ajustar a data/hora de chegada, edite as constantes `START` e `ARR` no início do script.
Abra com `#chegou` no final do link para pré-visualizar a tela de chegada.
